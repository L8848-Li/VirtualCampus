# v0.2 运行与验收

## 运行

在项目根目录执行 `npm run dev`，打开 http://127.0.0.1:8765 。无需安装依赖；也可直接用浏览器打开 index.html。直接文件访问的本机存档支持取决于浏览器，建议用本地服务。

## 完整交互

1. 输入种子，创建世界。十人有固定兴趣和习惯，性格在种子控制下微调。
2. 单步或自动推进。七天，每天四时段；顶部显示下一时段，地图底部明确标注画面所属时段。
3. 点击地图、名单或关系节点选择角色。档案显示选择理由、需求、目标、关系和重要记忆。
4. 点击 ☆ 关注最多三人。开启跟随观察，会持续高亮当前角色并显示相处状态；地图保持全校园视图。
5. 三种干预改变宿舍、课程组和下一时段活动吸引力。NPC 自己选择是否参与，七天结束后禁用干预。
6. 切换 TA 看别人 / 别人看 TA，观察有方向的关系。颜色和线型区分亲近、紧张和心动；节点可点击，数值列在图下。
7. 时间线可筛选重要片段、所有关系、关注人物、所选角色或全部事件。为什么发生会显示原因、评分分项、双方解释及前置事件。
8. 每日手记选择不同关系的重要片段，所有事实仍能追溯原始事件。
9. 每次推进、干预及观察设置变化都保存到当前浏览器。刷新后恢复并暂停。导出 JSON 用于备份或换浏览器，导入先重跑校验再恢复。
10. 重放依据相同引擎版本、种子和干预序列重新执行到当前进度，并比较状态校验值。

## 自动检查

`npm run check` 检查全部 JavaScript 语法与页面资源引用；`npm test` 执行：

- 100 个种子 × 28 步的逐步重放、需求边界、地点、有限记忆、因果 DAG 与周期停止。
- 已知关系影响行动，负面关系可改变去处，同一时段目击习惯可以支持寻找。
- 受邀者独立接受和拒绝，旧目击导致扑空。
- 含待执行干预的存档往返，以及恢复后未来结果一致。
- 无效版本、错误校验、未知干预、乱序和超界存档拒绝。
- 多种子实际出现主动邀约、接受、婉拒、擦肩、心动与澄清；内向者也能心动。

## 已知边界

移动是表现层的路径动画；四时段模拟仍离散结算。跟随观察提供持续高亮和状态，不做缩放镜头。没有完整多步规划、第三方传话或任意命题的信念模型；误解由具体场景规则产生。暂无跨版本存档迁移，v0.1 文件会给出不兼容提示。自动保存是本机、当前浏览器与当前页面来源的存档，不同步到云端。
