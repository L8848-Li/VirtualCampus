# v0.4 本地运行与验收

## 运行

Node.js 22.12+（建议 24 LTS）。首次 `npm ci`，然后 `npm run dev`，打开 http://127.0.0.1:8765 。本版通过 Vite 运行，不直接双击源码 HTML。

`npm run build` 生成 dist；`npm run preview` 在本机检查构建文件。无需模型密钥或后端服务。

## 交互验收

1. 新建世界，单步或自动运行；暂停与加速不改变结果。
2. 选择角色、关注最多三人、跟随观察，切换关系图两种方向。
3. 三种干预分别改变宿舍、课程组和下一时段社团吸引力。
4. 档案显示当前计划及阶段；寻找、答应未来饭约、赴约、等待和取消都有事件记录。
5. 共同事务面板显示各小组进度；实际工作、分组变化、完成和错过截止均可追溯。
6. 查看为什么发生：候选评分包含承诺与切换成本，并连接相关记忆、约定、任务和环境事件。
7. “那些还惦记着的事”按事务串起提议、推进、等待、取消与后来的解释。可筛选关注人物和未解故事，展开后事实与人物判断分开。
8. 人物档案展示有来源的理解；简短回应与失约的私人原因不会远程传达。实际相遇后可以解释，也可能保留疑问。
9. “想和大家做点什么”显示 NPC 自主发起的小聚、实际准备量、答应与到场人数。准备不足或缺席均可使活动取消。
10. 校园手记回看每日代表片段，七天结束自动暂停。
11. 刷新恢复并暂停；导出 / 导入会重跑校验；损坏和不兼容存档被拒绝，旧版本机存档键保留。
12. 重放同版本、种子与干预序列，提示校验一致。

## 自动验收

- `npm run check`：TypeScript 与 Vue 类型检查。
- `npm test`：135 项测试，包括 100 个种子的每步重放、状态边界、局部信息、邀约、计划持续、任务贡献、存档、认知来源、解释失败、自主筹备、真实到场、纯读取故事与跨事务后果。
- `npm run evaluate`：100 个种子，28,000 次角色行动，生成可读指标报告。
- `npm run build`：静态构建。

认知、活动与故事的设计约束见 [本轮说明](ITERATION-v04.md)。自动检查用于检验机制合法性与复现；趣味性仍需要实际试玩反馈。

浏览器已检查 1240 与 390 像素宽度的布局、单步至第三天、实际办成的小聚、完整故事展开、人物判断回到交流来源、重放校验及刷新后暂停恢复。[故事卡实拍](images/stories-v04.png)与[校园实拍](images/campus-v04.png)来自同一个 `campus-2026` 世界。

## 边界

跟随提供持续高亮与状态，地图仍显示全校园；移动是表现层补间。目标固定，尚无完整多步搜索、第三方传话或任意命题信念。认知仅覆盖两种有具体经历的判断，兴趣小聚一周最多一场；活动结果不会自动广播给缺席者。存档只保存在当前浏览器来源，没有云同步与跨版本迁移。
