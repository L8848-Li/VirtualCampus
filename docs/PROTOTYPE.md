# 赛博校园 · 七日观察

## 运行与完整交互

直接用浏览器打开 index.html，或在本目录运行 `npm run dev` 后访问 http://127.0.0.1:8765 。零安装，无需模型密钥；字体完全使用系统字体，无网络请求。

1. 输入世界种子，点新建世界。默认暂停，十人在宿舍。
2. 单步执行一个时段，或继续自动运行。速度为 2200 / 900 / 250 毫秒一步，暂停和速度不影响随机序列。
3. 点击地图小人或角色列表，查看性格、目标、需求、单向关系、宿舍、课程组和最近八条亲历记忆。
4. 下一步前可宿舍重排、课程随机分组、举办社团开放日。宿舍与分组持续生效，活动只影响下一步。干预不保证剧情。
5. 时间线支持关系、全部、角色、干预筛选。查看因果可递归追溯前置事件、评分和数值变化。每天结束后校园墙生成摘要。
6. 28 步后自动暂停，继续查看档案与日志。点重放将同种子与原时段干预重新执行到当前进度并比较完整状态；新建世界清除干预。导出 JSON 可保存记录，当前无导入按钮与自动存档。

## 架构

- src/engine.js：无 DOM 的确定性规则内核，浏览器和 Node 共用。
- src/app.js：墙钟计时器、选择角色、干预、导出、因果弹窗和视图渲染。
- index.html、src/style.css：地图、档案、干预区、时间线、校园墙及响应式布局。

世界状态包括种子、PRNG 状态、tick、NPC、环境、日志和干预输入。七天每天四时段，0–28 步。计时器仅决定推进频率；模拟不使用系统时间或 Math.random。

每步执行：需求衰减 → 行动评分 → 最大分选择与地点迁移 → 同地配对 → 关系互动 → 有限记忆更新 → 时段推进 → 日终摘要。

NPC 有外向、敏感、进取三个 0–1 性格值，交友、奖学金或归属目标。休息、吃饭、上课、自习、社团的评分由需求、性格、目标、时段、活动与种子噪声共同决定。行动记录全部候选分数。休息恢复精力，吃饭消除饥饿，学习增加进度，互动缓解社交需求。

NPC 只与当前位置的人相遇；宿舍需同室。每人每时段最多一次互动。规则优先级：紧张关系澄清 → 敏感度和亲历负面记忆触发误解 → 学习地点且进取差异超过 .35 触发竞争 → 好感超过 14、外向性和检定满足触发单向暗恋 → 普通友好交流。同课程组增加正向变化。好感、信任、心动均有界。

NPC 最多记住八条亲历事件，玩家可观察全局历史。旧日志不能被 NPC 全知读取。当前误解是敏感度与记忆驱动的简化误读，没有第三方传话或复杂信念模型。

事件保存 ID、时段、参与人、类型、规则数据与 parents。父事件严格早于子事件，形成可追溯 DAG。行动指向角色上次事件和最近干预，互动指向双方行动及最近干预，每日摘要指向当天关系事件。此为执行因果追踪，不是反事实因果证明。

## 验收

运行 `npm test`：已通过 100 种子 × 28 步的逐步完整重放一致性、地点与需求边界、八条记忆限制、因果 DAG、周期停止、同种子一致及异种子差异检查。

手动流程：单步 → 点角色 → 三种干预 → 播放/加速/暂停 → 因果弹窗 → 每日手记 → 七日停止 → 重放校验 → 导出。

## 已知边界与后续

地点移动按时段离散呈现，无连续寻路。目标固定，无复杂规划、第三方谣言传播、死亡机制或自由对话。校园墙采用确定性模板摘要。刷新页面会重置，导出用于留存。

后续可加存档导入、局部信念、活动日历、关系图。可选大模型仅接收已确定事件生成对白与叙事，不反向修改模拟状态，保留无密钥可玩及规则重放。
