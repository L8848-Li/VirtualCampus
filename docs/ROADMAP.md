## 为什么现在显得简陋

1. **世界像状态面板。** 小人切换地点后就静止，无法感知走路、等人、独处或一起做事。
2. **认得出名字，但记不住人。** 性格被压缩成三个标签，角色缺乏习惯、兴趣、背景与稳定行为特征。
3. **关系没有充分反哺行动。** 好感和信任会变化，但行动选择并不考虑某人在哪里；朋友不会主动等对方，紧张关系也不会主动回避。
4. **事件没有具体对象。** “因一句话误解”没有说明哪句话、围绕哪件事、谁掌握什么信息，后续也很少承接。
5. **记忆保存太短、用途太窄。** 八条记忆混合行动和互动，重要关系经历很快被日常移动挤掉，主要只影响误读概率。
6. **可复现已有，探索工具不足。** 重放只能比较一致性，不能建立两个世界观察“如果没有这次干预”。
7. **七天只有时间边界。** 缺少可以期待的周内安排与角色自己想完成的阶段性事情。

## 产品重心

观察生命与围观故事各占一半。建议主方向是“温暖、偶有尴尬和狗血的校园观察箱”。赛博感放在观察设备、回放与因果界面上，校园本身先采用柔和的 2D 微缩风格。

玩家体验循环：认出几个人 → 注意到一次互动 → 记住一段关系 → 改变环境 → 等待自主选择 → 追溯结果 → 想试另一种可能。

## 方向一：让校园看起来在生活

- 角色拥有稳定的头像、配色、轮廓和小动作；点击后显示名字与当前意图。
- 建筑内有饭桌、书桌、长椅和宿舍床位；小人呈现独处、并坐、交谈、等待等状态。
- 在模拟时段之间播放沿校园道路行走的短动画。动画进度只影响呈现，不参与规则或随机序列。
- 地图增加清晨、午后、夜晚色调，以及有上限的活动气泡。
- 提供跟随某人的镜头与三人关注列表。重大关系变化时高亮，普通吃饭不打断。
- 移动端先展示地图与当前关注角色，把详细关系和原始规则数据折叠。

验收：无需打开完整日志，玩家能说出“谁和谁在一起、谁独处、谁在等人”。

## 方向二：让角色有可以被识别的个性

- 为十人设计兴趣、社交风格、时间习惯、一个可观察的小执念。
- 角色档案区分公开资料、玩家观察与角色私有想法，避免把全局信息送进 NPC 决策。
- 兴趣进入行动评分：摄影者更常去社团、学霸有固定自习习惯，但需求仍可改变选择。
- 内向角色也能产生亲近和暗恋，通过低频但重要的互动积累，而不是靠外向门槛决定资格。
- 目标从静态标签变成小计划：找项目搭档、报名活动、完成作业、修复某段关系。
- 行动失败可调整计划；不预设恋爱配对或指定结局。

验收：隐藏姓名后，仍能通过一周行为分辨出几个人；目标确实改变行动权重。

## 方向三：让关系改变下一次行动

给行动评分增加局部可知的社交因素：

- 昨天一起吃饭很愉快 → 今天尝试再次邀约。
- 听到对方可能去图书馆 → 去那里碰碰运气；信息可能已经过时。
- 上次被拒绝 → 暂时回避或尝试澄清，取决于性格。
- 共同作业临近截止 → 主动寻找组员，而不是随机同地才互动。

提出邀约时，对方独立评估精力、信任、时间安排与自己的目标，有权拒绝。关系数值区分好感、信任、熟悉、紧张和心动，并允许双方认知不对称。

验收：同种子改变某段关系后，在后续行动中能看到明确差异与对应评分来源。

## 方向四：把一句事件长成故事弧

以具体事务为核心，采用带状态的规则链，而非预写整段剧情。

例：共同作业 → 发出邀请 → 有人迟到 → 参与者各自解释 → 下次见面时回避或澄清 → 关系留下痕迹。

每个阶段都有多种出口：精力不足可能取消邀约；另一位目击者可能补足信息；任务成功也可能让竞争加剧。系统不保证故事一定进入下一阶段。

记忆拆成事实、来源、当事人的解释、置信度和重要性。日常琐事快速衰减，重要关系记忆按显著性保留；当前八条亲历缓存可继续用于近期行动，但不再承担全部人物历史。

叙事模板填入具体场景与对象：从“发生误解”升级为“林夏以为周屿故意没来小组讨论，而周屿只知道临时改了教室”。需先由可追溯规则生成事实，再决定各人知道什么。

验收：玩家能从当前事件追溯出两到三次先前互动，且每名角色的反应符合其掌握的信息。

## 方向五：让干预成为可思考的选择

- 活动提前安排：地点、时段、主题决定吸引谁，精力不足的人仍可缺席。
- 资源变化：延长图书馆开放、关闭一间自习室、改变食堂座位容量。
- 宿舍与课程分组：提供当前结构预览，让玩家理解改变了哪些相遇机会。
- 每日有限干预额度，让“今天什么也不做”也有价值；额度是可调玩法选项。
- 干预前解释可能影响，干预后显示实际选择，避免承诺固定结果。

验收：同样是办活动，不同主题与时段有可理解的参与差异。

## 方向六：把观察工具做成独特玩法

- 关系网络：选一个人，展开“TA 怎么看别人”和“别人怎么看 TA”。默认少量重要边，避免十人全连线。
- 故事关注：标记一对关系，只汇总相关交集与未知信息。
- 每日手记：把统计改成两三个真正影响关系的片段，保留事件链接与事实来源。
- 观察者与角色视角切换：玩家知道的事实，与角色相信的解释并排展示。
- 世界分叉：同种子、同历史，在某时段复制出另一个分支，只改变一个干预。对比相遇、关系和故事差异；说明随机序列连锁变化也可能带来差异。
- 导出分享包含版本、种子、输入与校验信息的重放文件，先做文件导入，再考虑分享服务。

## 建议版本切分

### v0.2：让人愿意继续看

- 自动保存 / 导入，并引入 schemaVersion 与 engineVersion。
- 校园移动表现、昼夜变化、跟随 / 关注角色。
- 角色卡与可筛选关系图。
- 事件按重要性排序，每日汇总有代表性的变化。
- 保持当前四时段逻辑与七天边界，控制范围。

### v0.3：让人真的在意彼此

- 行动目标可包含某个人或某个共同任务。
- 邀约、等待、拒绝、回避与澄清。
- 关系和重要记忆参与行动评分。
- 验证干预与关系变化确实影响后续行为。

### v0.4：让故事留下后劲

- 具体事务、局部信息、传话与误解链。
- 少量校园周历锚点：小组任务、社团筹备、周末展示。它们制造条件，不指定人物结局。
- 基于事实的每日日记与七日关系回顾。
- 世界分叉比较。

暂缓 3D、大规模 NPC、实时多人、账号系统和强制大模型代理。优先把十人的可识别性、关系连续性和观察体验做扎实。
