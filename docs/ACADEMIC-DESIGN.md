# 校园学业系统：讨论草案

状态：v0.5 已实现普通教学周的两门虚构课程、课表与基于实际行动的出勤；作业成绩、考试、挂科及取得学分仍为提案。下文其余内容描述后续方向。

希望课表、上课、作业、考试与学分产生可观察的校园生活：角色有自己的课程、压力和选择，可能准备充分，也可能因为其他安排错过学习、考试失利，随后寻求帮助或调整计划。玩家观察并调整公共环境，人物自主决定如何安排时间。

## 和现有模拟如何衔接

当前世界是 10 人、11 个可到达的模拟地点、7 天、每天 4 个时段；“上课”和“学业进度”目前是简化行为，不代表真实课表或成绩。现有的小组报告、学习行动、饭约、兴趣活动、休息需求和人物记忆都可成为学业系统的基础。

后续可用“期末周”场景验证一周：开局给每位角色生成可追溯的学期基础、课程与已完成的平时任务，接下来七天经历复习、考试、成绩公布。开局以前的进度应明确标为此前累计，不能假装是这一周发生的事件。普通教学周则先展示课程、出勤、作业及测验，完整学期与长期毕业进度留待时间系统扩展。

## 课程与课表

- 课程有名称、类型、学分、上课地点、课程时间、考核方式、截止时间和考试安排。示例课程和权重应明确为虚构设定，不能冒充现实学校的具体培养方案。
- 每位角色有个人选课与课表：可设少量共同必修和一门兴趣选修。课表是时间约束与动机，人物仍有可能迟到、请假、缺席或选择处理更紧急的事。
- 以现有上午、午后、夜晚等粗粒度时段先表达课程和复习；午间留作吃饭与相遇。需要更细节次时，再引入课节与模拟时钟，避免把一整个时段误说成一次精确的真实课程。
- 界面在人物档案展示“今天的课 / 下一次作业 / 接下来的考试”，同时提供每周课表。点击课程可看到已发生的上课、缺席、学习和作业事件。

## 学习、作业与成绩

每门课分别记录个人理解、实际出勤、作业结果和考试准备。课堂、独自复习、与同学讨论、项目实践可以以不同效率推进学习；能力倾向、既有基础、疲劳、时间冲突和实际投入共同影响结果。多次学习应有递减收益，避免无限刷分。

成绩结算应使用可配置的课程考核方案。比如一门虚构课程可以设置“过程成绩 40% + 考试成绩 60%”，考试受该课程理解、考前准备、状态和受控随机波动影响；此比例只用于说明，不能作为北邮统一制度。成绩产生后保存组成依据与版本，结果不应仅由性格或一次随机数决定。

课程通过后获得该课程学分，未通过时保留未完成记录，同一课程重复通过不得重复累计学分。课表中的计划修读学分、已修学分和未完成学分分别展示；阶段目标可有弹性，不把人物归类为单一的“好学生 / 差学生”。

## 考试、挂科与后续

1. **考前**：发布考试安排和复习机会。角色决定是否参加复习、询问同学、维持休息或去赴约；每种选择占用实际时间。
2. **考试**：到了时间，角色需实际选择并到达对应地点才能参加。缺考、申请缓考等如要加入，必须先有明确事件和处理条件。
3. **公布**：到公布时间才生成成绩与通过状态。个人成绩属于个人信息；其他 NPC 需要本人告知等明确渠道才知道。
4. **不及格**：产生一条有后续的个人问题，可根据课程类型和规则走补考、重修或其他路径。角色可能主动复习、找人求助或先处理自己的情绪，结果取决于后续实际行动。
5. **长期结果**：补考、重修、学分统计及毕业审查需要跨周 / 学期时间。七天原型可以展示明确标注的后续安排，但不在同一周自动伪造一个完整学期。

现有七天的自动停止不适合直接完成多学期重修：可以先提供“期末周试验场景”，验证一次失败、一次补救安排和可追踪后果，再决定如何延长存档和模拟时间。

## 让学业产生故事

- **一起复习**：A 约 B 去图书馆。双方可自主接受、拒绝或中断；实际共同复习才可能带来学习收益与关系变化。
- **共同报告的付出**：沿用已有贡献记录；谁做了事、谁看到了、谁获得认可分别记录。不满取决于人物知情范围、约定和性格，不直接由差值触发。
- **考前取舍**：一次复习与期待已久的小聚撞期，人物可能选任意一边，也可能因疲劳先休息。玩家能通过调整公共学习资源提供机会，不能指定其行动。
- **成绩之后**：一位角色考试失利，是否愿意向朋友求助、是否把结果告诉别人，由人物及信息渠道决定。另一人即使考得很好，也可能选择安静陪伴。
- **差异化目标**：有人关注奖学金，有人只求通过，有人在意兴趣课或合作作品。成功的意义因人而异，挂科不直接等于人物失败或玩家输掉游戏。

## 玩家干预和观察

优先考虑延长图书馆开放、增加共享学习资源、开放自愿参加的公共复习活动；干预前说明地点、时间、持续和可能涉及的人，事后可追溯实际影响。保留“等待”的选择，不提供直接改分数、强制上课、指定谁帮助谁的按钮。

界面分为个人课表、课程详情、成绩与学分、学业故事。观察者可查看世界事实及不同人的了解情况，但 NPC 只能读取自己的课程、亲历与实际收到的信息。成绩、学业困境和私人求助不应自动广播给其他人。

## 建议的迭代顺序

1. **课表与时间冲突**：两门示例课、个人课表和出勤；学习与饭约、活动、休息参与同一决策。验证能上课、能缺席、原因可追溯。
2. **作业与共同复习**：接入已有报告与记忆，加入自愿学习和明确截止，验证投入需要实际行动且别人不会自动知道。
3. **考试与成绩**：配置期末周情景、过程成绩、考试和延迟公布；验证同输入可复现、成绩有依据、缺考与未参加分开。
4. **学分与补救**：记录通过和未完成学分，支持一次可复现的补考或重修安排；处理重复学分及课程类型，保持其他人物的信息边界。
5. **学期和毕业**：评估多周时间、课程种类、学期存档与旧档兼容后再加入。每阶段都要试玩，观察玩家能否说清“为什么失利、之后怎样应对”。

## 现实制度参考与待定问题

北邮学生处公开的[学生管理规定](https://xsc.bupt.edu.cn/info/1065/1281.htm)区分考试与考查，并将课程考核、学分与培养方案联系起来。教务处公开的[补考说明](https://jwc.bupt.edu.cn/info/1273/2774.htm)和[重修选课说明](https://jwc.bupt.edu.cn/info/1254/2768.htm)显示补考、重修会因课程类型和具体情况而不同。这些材料可用于理解制度结构；具体年级、课程、成绩比例及当前执行规则仍需按学校和学院当期通知核实，游戏应将参数与学校真实规定分开。

待一起决定：第一版先从“普通教学周”还是“期末周”进入；课程是否采用虚构名称；学业压力的基调是轻松日常、适度现实，还是更紧张；是否需要跨周延续，以及成绩对奖学金、毕业等长期目标的影响范围。
