# v0.17 架构与存档

项目继续使用 Vue 3、TypeScript、Vite 和本地静态部署。12 位人物、168 时段、全部校园日常规则及生活实验保持原有行为；没有新增生产依赖。

本文与[迁移说明](MIGRATION.md)、[性能报告](PERFORMANCE.md)记录当前交付状态。`internal-docs/` 保存本地历史设计与测量材料，沿用仓库忽略规则；旧任务书中的候选方案与验收状态不自动代表当前实现。

## 世界操作与规则

`World` 是操作入口，保留 `step()`、`intervene()`、`replay()`、`toSave()`、`fromSave()`。`WorldState` 明确列出全部模拟状态，包括随机数状态、种子、时段、输入、干预环境、人物和服务；界面状态、事件索引和评分缓存不属于这个状态。

`core/tick.ts` 按下列固定顺序运行：

1. 假期离返校、需求变化、服务通知、日历、截止与计划。
2. 所有人基于移动前的信息选择行动，然后统一执行行动与移动。
3. 餐饮排队及美食节、现场观察、课间事务和阶段测验。
4. 考核、图书馆、社团、组会、任务、作业、活动、宿舍、包裹与洗衣。
5. 宿舍订餐、生活实验、社交、时段递增和日终摘要。
6. 封存新增事件，再发布快照和自动保存。

调用顺序、行动候选顺序和随机数消耗都是行为契约。公共天气、移动前拥挤度可以在时段内复用；NPC 仍只接收本人的状态、通知、记忆、目击及公开信息。共享课程数据集中在 `courseCatalog.ts`，数值工具位于 `math.ts`，避免规则与决策之间的运行时循环引用。

## 当前状态、历史与评分

`EventLog` 在一个操作内部保存待完成事件；只有待完成事件可补写窗口、目击等信息。构造、干预、推进结束时，新事件的 JSON 数据被脱离引用并递归冻结。事件 ID 连续，父事件始终在前；人物状态与事实历史分别保存。

控制器快照复制可变状态，共享已经冻结的事件对象，并独立持有事件数组。旧快照不会读到后续事件，也不会修改世界。规则层的历史查询包含本时段已经产生的待提交事件，界面只取得已提交记录。

`ActionScoreStore` 以事件 ID 关联完整评分。行动名称按首次出现顺序放入字典；每行是名称 ID、地点、目标，以及九个评分分项。分项沿用原来的两位小数，按百分之一存入私有 `Int32Array`。`World.getActionScores(eventId)` 只还原指定表格并冻结结果；缓冲区不会暴露给调用方。界面只缓存当前打开的一份评分表，重放、导入和重置通过世界实例身份使缓存失效。

新增评分的名称、长度及全部整数内容形成摘要；事件提交时将事件 JSON、评分摘要和前一历史摘要合并。`checksum()` 只序列化当前 `WorldState` 并组合历史摘要。评分和历史无需在每次保存时重新展开。`checksumFromScratch()` 从全部记录重算，供完整测试独立核对；种子散列与随机算法保持原样。

## 查询与界面

`eventIndex.ts` 使用派生的时段、人物、类型和事务 ID 索引。索引通过弱引用与事件数组关联，不参与存档校验，不成为另一个事实来源。快照共享追加式索引，同时受自身数组长度限制；新世界使用新的索引。一般查询也支持非连续 ID 的事件子集。

事件流每页 100 条，故事卡每页 6 张，单段故事经过每页 50 条。关闭的故事与经过不创建正文节点。因果追溯可以临时显示全部事件以定位目标，返回时恢复原筛选、分页和滚动位置。全部记录、主观判断、原始规则数据和评分仍然可访问。

## 版本与恢复

引擎版本为 **0.17.0**，存档 **schema 4**。正常存档键为 `virtualcampus.save.v17.0`，开发测量键为 `virtualcampus.performance-test.v17.0`。

存档仍仅保存种子、时段、有序干预、生活实验选项、版本和校验。导入先验证边界，再从种子重建世界，最后核对校验；不接受外部人物状态。每次推进与干预立即写入小存档；只有写入成功才显示保存成功。视图变动复用当前有效存档。

旧的 `virtualcampus.save.v16.0` 数据保留。设置面板检测到旧记录时提供原样下载备份，v0.17 需新建世界，不自动迁移或覆盖旧数据。

## 验证边界

`npm test` 保留全部定向规则要求，并执行代表种子及关键恢复时段。`npm run test:full` 将同步推进扩展为 0–99 共 100 个种子、生活实验关闭/开启两种模式；每时段检查状态、所有新增事件与紧凑评分、资源和因果边界，终点完整比较两个世界。恢复入口由种子 0、1、99 在两种模式下分别覆盖全部指定检查点并续跑至结束。

`tests/fixtures/v016-behavior.json` 捕获自原版 `b5fa1c1`：六组世界的初始帧及逐时段状态、事件、完整评分的规范 JSON SHA-256，另含 100 种子首周评估。对照只排除版本标签与存储表示。生成脚本只允许在原版引擎执行，验证不会重写基线。

测试改为逐步比对与关键点恢复，不再逐个穷举所有从头重放前缀。完整日志封存、独立重算校验及原版行为摘要共同检查这个边界。相同场景的只读观察共用一次运行；场景运行器没有跨文件全局世界缓存。
