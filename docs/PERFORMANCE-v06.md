# 电脑端性能记录 v0.6

目的：建立可重复的早期基线，不把少量样本当作性能保证。测试为本机桌面浏览器、Vite 开发模式、默认种子、10 人和七日模拟，不代表生产构建或更大人口。

在开发模式通过 `?perf=1` 开启测量，并使用独立测试存档。点击“下一时段”、地图“放大”、概览中人物时，记录从点击事件到第二次浏览器动画帧回调的时间。结果包含浏览器帧调度和 Vue 更新，只是接近画面更新的粗略估计，不能当作纯计算耗时或严格的绘制完成时间。普通入口不显示测量，正式构建不启用。

本机一次探索性采样（作业截止时间和权重最后一次调整前）：推进 6 次约 16.4–31.3 ms、放大 6 次约 21.2–30.9 ms、打开人物 2 次约 20.8–32.5 ms。不同点击时模拟进度和页面状态不完全相同，样本数量少，不能推断百分位或设备间差异。早期 v0.5 的三个点击被连续触发，测量窗口重叠，因此不用于可靠前后对比。

本次减少了校园视图下未打开的人物故事面板计算，并将单人出勤查询改为一次事件扫描；现有模拟事件、可重放行为与个人信息边界不应因性能改动而改变。尚未测量生产构建的大样本、长时间运行、更多人物、内存或低配置电脑；后续应在一致场景下重复测量，必要时使用浏览器性能面板定位实际热点。
