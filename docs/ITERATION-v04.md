# v0.4：让一件小事留下后来的影响

本轮围绕三个连续目标：看得懂一件事，理解人物之间的信息差，观察人物自己把愿望变成行动。保持十人、五地点、七天、每天四时段和三种环境干预，无新增运行时依赖。

## 持续追看的故事

饭约、报告与兴趣小聚以稳定编号聚合，每一片段都来自已发生事件。原始提议与拒绝、实际推进、等待、取消和之后的解释共同保留。独立关系问题按人物对聚合，避免重复猜测淹没界面。

一张卡分为事实、人物理解、后续牵挂与完整经过。猜测不进入事实列表，认知问题可以在事务结束后继续存在。默认展示六张，支持展开其余故事、关注人物和未解事项筛选。阅读不会推进模拟、消耗随机数或改变人物。

## 信息差与解释

首版只建模两种具体情况：实际听到简短回应，却不知道当事人的疲劳、专注或独处需求；实际等不到赴约者，却不知道对方改变安排的原因。每条判断都有本人亲历的来源、置信度、证据和关联事务。

私人原因由当事人独立保留，未来计划被替换后也能回忆。只有实际同地交流时，当事人才可能说出原因；接收者按信任与敏感度更新判断，也可以继续怀疑。同一句解释不会被重复视作新证据。未解的简短回应不会反复生成同类猜测扣关系。

本轮没有第三方传话、任意命题推理或公共帖子传播。校园手记是观察者的摘要，不向 NPC 自动广播。

## 自己发起的小聚

第 2 至第 5 天之间，一次真实的正向交流可能激发某位人物筹办兴趣分享会的愿望。具体发起人由性格、处境与可复现随机判断产生。每周最多一场，安排在未来的午后。

发起人当面邀请实际遇到的伙伴，对方独立接受或拒绝，拒绝后不反复施压。每人只根据自己收到的邀请、活动时间和自己的准备量行动，筹备与赴会和课程、报告、饭约、吃饭、休息共同竞争。到场承诺有权重，紧急需求仍可使人缺席。

小聚需要四点实际准备量，每次自主筹备贡献两点。到期时材料足够、发起人在场且至少两名同意参与者实际选择出席，活动才办成。只有现场人物得到活动结果的亲历记忆及共同经历收益；缺席者不自动获知别人是否到场。重新分组不改写活动参与意愿。

## 复现与存档

规则版本更新为 0.4.0；导出格式仍是 schemaVersion 3 的输入重放格式。新本机存档使用独立键，旧键保留。跨引擎版本导入会明确拒绝，避免产生看似相同、故事却漂移的世界。

新增认知与活动随机数按用途、人物及事件派生，不消耗通用随机序列。原有行动、社交和环境尚未完全拆流，世界分支对照仍留待后续。

## 验证与下一步

类型检查、135 项测试、100 个种子的 28,000 次人物行动评估与生产构建均通过。固定评估场景是在第一个午后举办一次开放日，对照不干预的世界。当前报告见 [behavior-v04.json](reports/behavior-v04.json)：小聚既有成功也有取消，人物判断存在修正和保留疑问，所有判断均有本人经历的来源。指标是行为观察，不是趣味性结论。

后续优先根据试玩观察：玩家是否能讲清一个跨天故事，是否关心某人的愿望，是否理解拒绝与失约。可再扩展实际贡献被谁看见、有限的第三方求证及世界对照；需要先补充对应的信息接收和验收规则。
