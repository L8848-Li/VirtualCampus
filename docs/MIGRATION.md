# Vue / TypeScript 迁移验证

迁移前保存了 v0.2 的 100 个种子、每个 28 时段的完整状态校验值。

在只改变语言与模块加载方式、尚未加入新玩法的阶段，独立运行 TypeScript 内核，对 2,800 个检查点逐一比较，全部与原 JavaScript 内核完全一致。原有九项模拟、行为与存档检查也在 Vitest 中迁移运行。

界面拆分为地图、人物档案、关系图、校园墙、时间线和事件弹窗；控制层接收命令并发布普通数据快照。模拟核心不依赖 Vue，Vue 不代理或直接修改 World 实例。

后续 v0.3 新增计划与事务，是有意改变规则的独立阶段；同一个种子的故事可以因此变化。新增规则由行为测试、质量指标和版本化存档校验覆盖，不应将 v0.2 的结果强制当作 v0.3 的期望。
