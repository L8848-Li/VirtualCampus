# VirtualCampus · 赛博校园

> 十个独立的小世界，在同一座校园慢慢交织。

一个校园背景的半上帝模式微型生命模拟器。观察 10 位 NPC 自主上课、吃饭、休息与社交，通过改变环境影响相遇，围观友情、暗恋、误解与竞争自然形成。

**当前为 v0.1 规则原型。** 无需大模型 API 密钥，无运行时依赖，纯本地运行。角色自主决策与完整事件记录已经可玩，视觉表现、长期关系动机与叙事仍待打磨。

## 开始玩

下载或克隆后，用浏览器直接打开 `index.html`。也可以使用 Node.js 22+：

```sh
git clone https://github.com/L8848-Li/VirtualCampus.git
cd VirtualCampus
npm run dev
```

打开 http://127.0.0.1:8765 。无需 `npm install`，无后端服务。端口被占用时：`PORT=8766 npm run dev`。

## 如何观察

1. 输入种子，新建一个校园世界。
2. 选择「下一时段」，或「继续」并调节速度。
3. 点击小人，查看性格、需求、目标、关系和有限记忆。
4. 重排宿舍、课程随机分组，或举办社团开放日。
5. 阅读事件、查看因果链，日终在校园墙回看当天交集。
6. 七天结束后「重放」，验证相同种子与干预能产生相同结果。

导出 JSON 可留存世界与干预记录；当前尚不支持导入或自动存档，刷新会重置。

## 当前能力

| 部分     | 已实现                                                   |
| -------- | -------------------------------------------------------- |
| 校园     | 宿舍、教学楼、食堂、图书馆、社团中心                     |
| 时间     | 7 天 × 4 时段，单步、暂停、继续与加速                    |
| 角色     | 10 人，性格、需求、固定目标、单向关系、最近 8 条亲历记忆 |
| 决策     | 基于效用评分的行动选择，同地点局部互动                   |
| 故事     | 友好交流、误解、澄清、竞争、单向心动                     |
| 干预     | 宿舍重排、课程分组、下一时段社团活动                     |
| 可解释性 | 行动评分、规则原因、数值变化、前置事件追溯               |
| 可复现   | 种子 PRNG、带时段的干预记录、同版本重放校验              |

## 开发

```sh
npm run check
npm test
```

`npm test` 对 100 个种子的七日周期逐步校验重放、需求边界、地点合法性、记忆限制、因果图与终止行为。GitHub Actions 对 Node.js 22 / 24 运行相同检查。

```text
index.html                 页面入口
src/engine.js              独立规则内核（浏览器 / Node）
src/app.js                  控制、界面、导出与因果弹窗
src/style.css               地图与响应式样式
scripts/dev-server.cjs     本地开发入口
tests/engine.test.cjs       确定性回归检查
docs/PROTOTYPE.md           交互与机制说明
docs/ROADMAP.md             产品诊断、玩法脑暴、版本优先级
```

本地服务仅绑定 `127.0.0.1`。项目没有 Sites 配置、部署流程、远程字体或模型服务调用。

## 继续往哪里走

下一阶段围绕三件事：**认得出人、看得懂关系、关心接下来会发生什么。**

- **v0.2 观察体验**：小人移动、跟随角色、关系图、重要事件提醒、存档与导入。
- **v0.3 社交动机**：主动找人、回避、邀约、具体记忆与局部信念。
- **v0.4 故事弧**：合作任务、校园活动、传话与误解、关系变化的日终叙事。

以上为计划，未实现部分请参见 [路线图与脑暴](docs/ROADMAP.md)。大模型仅考虑作为可选对白层，保留规则版完整可玩路径。
